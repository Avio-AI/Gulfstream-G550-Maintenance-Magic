⬡ API KEY REQUIRED
To use the AI diagnostic assistant, enter your Anthropic API key. It is stored only for this session and never transmitted anywhere except directly to Anthropic's API.

Get a key at console.anthropic.com → API Keys.
🔒 Your key is kept in memory only — it is cleared when you close the app. It is sent only to api.anthropic.com over HTTPS.
How to Use This App 👋
This app is like having a super-smart aircraft mechanic in your pocket. You tell it what is wrong with the plane's fuel system, and it tells you how to fix it. No experience needed to get started!
1
Check the Status Bar 🟡
The row of numbers near the top shows the health of each part of the fuel system. Green = everything is fine, yellow = something is off, red = there is a problem! Tap any item to instantly ask the AI about it.
2
Use the Quick Fault Shortcuts 🟠
See the scrollable row of buttons just above the keyboard? Those are shortcuts for the most common problems. Just tap one and the AI starts helping right away!
3
Type Your Own Question ✏️
Use the text box at the bottom to describe exactly what you see — like the fuel gauge is showing dashes or probe 3 keeps failing. The more detail you give, the better the answer.
4
Keep the Conversation Going 💬
The AI remembers everything in the session. Ask follow-ups like where exactly is that connector? or what tools do I need? — just like texting a knowledgeable friend.
💡
Good to know: This app has the full G550 fuel system Maintenance Manual (ATA 28) built in. It knows exact part locations, wire numbers, circuit breaker labels, and what every cockpit warning light means.
